def retrieveACTRfromDAS(self, daciRi: str, resource: Resource, originator: str, request: CSERequest | None = None) -> Generator[dict, None, None]: (source) ¶

Retrieve the access control policy rules (ACRs) for a given resource and originator by consulting the DAS.

This is a generator function that yields the access control policy rules (ACRs). ACRs are retrieved from the DAS as needed. Each request to this function call may result in a call to a DAS server.

Parameters
daciRi:strThe resource ID of the DAC instance.
resource:ResourceThe resource to check.
originator:strThe originator to check.
request:CSERequest | NoneThe original request to check. This is optional, but can be used to provide additional information to the DAS.
Returns
Generator[dict, None, None]Undocumented
Yields
Each access control policy rule (ACTR) as a dictionary.
