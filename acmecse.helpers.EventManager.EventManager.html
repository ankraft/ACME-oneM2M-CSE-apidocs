acmecse.helpers.EventManager.EventManager

class documentation

class EventManager: (source)

Known subclasses: acmecse.runtime.EventManager.EventManager

View In Hierarchy

Base class for an event manager. This class manages events and event handlers. It is implememted as a Singleton, so there is only one instance of the event manager in the whole application.

Event topics are added as new methods to an EventManager instance. Events can be raised by calling those new methods.

Example

manager.addEvent("anEvent")
Add new Event topic anEvent to manager.
manager.addHandler(manager.anEvent, handlerFunction)
Add an event handler for the anEvent Event.
manager.anEvent(anArg)
Raise the anEvent Event with an anArg argument.
