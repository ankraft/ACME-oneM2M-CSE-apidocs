plugins.runtime

package documentation

This package contains runtime plugins for ACME CSE.

In contrast to the modules in the acme.runtime package, the plugins in this package can be disabled by the user.

Module Console This plugin defines a rich console for the CSE.
Module MinimalConsole This plugin defines a minimal console for the CSE.
Module Statistics Statistics Module for internal statistics.
Module TextUI This module defines a textual UI for ACME CSE.
