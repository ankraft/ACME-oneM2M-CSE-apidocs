class PCH_PCU(VirtualResource):

Constructor: PCH_PCU(dct, create)

View In Hierarchy

Class for the PollingChannelURI (PCH_PCU) resource type. This is a virtual resource that represents the polling channel URI of a PollingChannel resource.
